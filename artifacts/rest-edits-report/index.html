01 / LISTEN FIRST

Short. Soft. Once.

Two rounded notes, a gentle onset, and a quick fade. No repeating alarm, sharp buzzer, or system-volume change.

Exact app audio graph rendered to WAV · about 1.6 seconds of sound · your device’s media volume applies.

When it plays

Once when the rest timer reaches zero. It works while moving between app tabs. Editing a saved set does not restart the timer. Skipping rest is silent.

You control it

Settings → Rest timer sound → Sound on/off. The choice persists after reload. Preview chime lets you try the sound even when automatic completion sound is off.

Keep the app open. Phone locking, background suspension, browser audio restrictions, and device volume can prevent a timely or audible chime. Existing visual completion feedback remains.

02 / CORRECT YOUR NUMBERS

Already saved?
You can still fix it.

DURING A WORKOUT

Edit the saved set

  1. Tap Edit set below the logged row.
  2. Change reps or weight.
  3. Tap Save changes.

The row updates and gains an Edited label. The set stays part of the same workout, and rest keeps its existing countdown.

AFTER A WORKOUT

Open it from Stats

  1. Go to Stats → Sessions.
  2. Tap Review / edit sets.
  3. Under Logged sets, edit the relevant row.

The workout date and available station names help identify the right session/set. Totals and highlights refresh after saving.

What “Edited” means

The values changed after the set was logged. The label stays visible after reload. Opening the editor shows the latest edit time and the original weight/reps. Saving unchanged values does not create an edit marker.

04 / IMPLEMENTATION DETAILS

Corrected values.
Preserved history.

  • Soft chime. A Web Audio module creates two sine notes with a gradual attack/fade. Nodes disconnect when finished, and rapid preview taps do not stack overlapping chimes.
  • Reliable completion behavior. The timer reads the current sound preference when it completes, including preference changes made during rest. The countdown now uses ceiling rounding so it does not finish roughly half a second early.
  • Reusable editor. One labeled, mobile-friendly form serves active and completed sessions. Rep input is selected for quick replacement. Cancel leaves saved values alone; invalid, unchanged, or busy saves are disabled.
  • Persistent edit metadata. The set stores editedAt and its first originalValues. Subsequent edits retain those original values. This is an original/latest record, not a complete revision-by-revision history.
  • Set identity preserved. Correcting weight/reps retains the set ID, workout ID, exercise ID, machine ID, set number, and original logging time. Workout finish time stays unchanged.
  • Current totals. The completed-workout summary reloads its totals and highlights after an edit. History/weekly views read the corrected records when reopened.
  • Strength suggestions corrected. If the old set values supplied the stored strength baseline, that baseline is recalculated from remaining valid sets. A higher corrected set can update an existing baseline.
  • Atomic data update. Validation and writes run in a transaction. A stale editor cannot silently overwrite a different correction; it asks for a reload. Duplicate save taps are guarded.
  • Existing data compatibility. Old sets have no edit marker until changed. Optional metadata travels with existing backup and sync records. The backup round-trip is tested; live multi-device sync was not tested.
  • Past sessions made accessible. Stats session cards now expose Review / edit sets. The summary displays the session date, grouped saved sets, station names when available, and paths back to Stats.

06 / Q&A

A few useful distinctions.

Can I correct only the reps?

Yes. Leave weight as it is, change reps, and save. You can also correct both values.

Why this matters: forgetting the actual rep count is the main reason for this feature.

Will an edit start another rest timer?

No. Only logging a new set starts rest. Correcting an existing set leaves the current timer alone.

Why this matters: an administrative correction should not interrupt the training rhythm.

Will editing an old session make it look longer?

No. Its original finish time and duration are preserved. Volume and highlights use the corrected numbers.

Why this matters: fixing reps should not rewrite when the workout happened.

Can I see every past revision?

The app retains the original values and the latest edit time, with the current values on the row. It does not keep a full list of every intermediate change.

Why this matters: an Edited marker is useful without promising a full audit-history system.

Will I hear the chime with the phone locked?

That is not guaranteed. Keep the app open; a suspended browser may not run the timer/audio promptly. The sound also follows device media volume and browser restrictions.

Why this matters: this is an in-app rest cue, not a native background alarm.
