Private account invitations.

Anyone signed in can send a link that lets someone create their own private account. Links work for 7 days, can be used more than once, and can be revoked at any time. The shared family code keeps working.

How it works

  1. Create a link

    In Settings, tap Create invite link. The full link is shown once, ready to copy or share from the phone’s share sheet.

  2. They sign up

    The link opens straight into signup. No family code needed. The server checks the link only when the account is created.

  3. Stay in control

    Recent links show when they were made and when they expire. Tap Revoke to stop one immediately.

Behavior

Private accounts

Every invited person gets their own account and their own data. Nothing is shared with whoever invited them.

Reusable for 7 days

One link can sign up more than one person until it expires 7 days after creation. It is not single-use.

Revocable anytime

Revoking stops new signups right away. Accounts already created with the link keep working.

Shown once

The server stores only a fingerprint of the link, never the link itself, and the app doesn’t save it either. Lost it? Revoke it and create a new one.

Anyone signed in

Any member can invite. Limits: 10 active links and 20 new links per day per person.

Family code still works

Create account with the shared code works exactly as before. An invited person can switch with Use an invite code instead.

Questions & answers

Why private accounts instead of joining the inviter’s account?

Training, food and body data are personal. A separate account means nobody sees anyone else’s numbers by accident, each person gets coaching that fits their own goals, and removing someone never touches anyone else’s history. It matches how the family code already works: everyone signs in as themselves.

Why do links expire after 7 days?

Links get forwarded, pasted into chats and left in message history. A week is long enough for someone to get around to signing up, and short enough that an old link turning up later doesn’t open the door.

Why make links revocable and reusable?

Reusable means you can send one link to a group, or resend it if the first try fails, without making a new one each time. The trade-off is that anyone holding it can sign up, so revoke is there to close it the moment it’s no longer needed or ends up somewhere it shouldn’t.

Is anything left to decide?

No. Who can invite (anyone signed in), how long links last (7 days), whether they’re reusable (yes) and the family code (kept) are all settled.
